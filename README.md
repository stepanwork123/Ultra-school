# Ultra School 🚀

Современная образовательная платформа для школьников.

## Возможности

- Главная страница и статистика обучения.
- Курсы по математике, английскому языку, истории,
  информатике, шахматам и музыке.
- Учебные задания с проверкой ответов.
- Локальный учебный помощник Ultra AI.
- Опыт, уровни и достижения.
- Виртуальные кристаллы.
- Профиль и выбор аватара.
- Локальный список друзей и виртуальные подарки.
- Сохранение прогресса в браузере.
- Кэширование файлов для офлайн-доступа.

## Файлы проекта

- `index.html` — структура сайта.
- `style.css` — оформление и адаптация под мобильные устройства.
- `app.js` — логика приложения.
- `sw.js` — кэширование для офлайн-режима.

## Запуск

Открой `index.html` в браузере.

Для корректной работы Service Worker и проверки офлайн-режима
рекомендуется опубликовать сайт через GitHub Pages.

## Публикация на GitHub Pages

1. Создай новый публичный репозиторий.
2. Загрузи все четыре файла в корень репозитория.
3. Открой Settings → Pages.
4. В разделе Build and deployment выбери Deploy from a branch.
5. Выбери ветку `main` и папку `/ (root)`.
6. Нажми Save.
7. Дождись завершения публикации.

Адрес сайта будет примерно таким:
https://ТВОЙ-ЛОГИН.github.io/ИМЯ-РЕПОЗИТОРИЯ/

## Важно

Это учебная демоверсия. ИИ-помощник использует локальные
правила, а не настоящую облачную нейросеть.

Данные профиля, прогресс, кристаллы и друзья хранятся
в браузере. Для настоящих аккаунтов, совместной работы,
синхронизации и подключения ИИ потребуется серверная часть.

Все кристаллы виртуальные. Реальные платежи не используются.
